# RecipeApp
RecipeApp is an app that allows users to search different recipes, save own recipes and select favourite recipes.
The app uses [Spoonacular API](https://spoonacular.com/food-api).

<img alt=recipe-tn src=https://github.com/user-attachments/assets/98edcfab-19b0-4d36-a46d-1b705b132625 width=400 />

## Features
- **Recipe Management**: Add, edit, delete and browse recipes effortlessly.
- **Today's Specials**: View random featured recipes each day.
- **Search & Filter**: Quickly find recipes based on keywords, ingredients, or categories.
- **Shopping List**: Create and manage shopping list.

### Upcoming Features
As part of a major refactor, I am building a web interface and a shared backend to enhance performance and usability. New features currently in development include:
- **Food Logger**: Log daily meals and foods to monitor eating habits.
- **Calorie Counter**: Track nutritional values of foods and recipes.
- **"What's in My Fridge"**: Discover recipes based on the ingredients you have available.
- **Protein Calculator**: Calculate the protein efficiency of foods.

## Getting Started
To get started with RecipeApp, follow these steps:

1. Clone the repository: ```git clone https://github.com/yourusername/RecipeApp.git```
2. Open Android Studio and select "Open an existing project."
3. Navigate to the directory where you cloned the repository and select the RecipeApp folder.
4. Connect a device or start an emulator
5. Run the app from Android Studio.

## Usage
- Launch the app
- Start adding recipes with clear instructions and ingredients lists.
- Search for recipes or filter by category to find inspiration.
- Get inspired by Today's Specials.
